# Screenshots

The main `README.md` embeds the following images from this folder. Drop the PNGs in here with these exact filenames so the links resolve.

| File            | Page         | Suggested content                                                                     |
|-----------------|--------------|---------------------------------------------------------------------------------------|
| `landing.png`   | `/`          | Workspace landing page. 1600x900 works best.                                          |
| `upload.png`    | `/upload`    | Extraction panel populated with title / authors / methodology after an upload.        |
| `chat.png`      | `/chat`      | A multi-paper question with an answer that has bold paper titles and citations open.  |
| `compare.png`   | `/compare`   | Two or three papers selected side by side.                                            |
| `graph.png`     | `/graph`     | 4-5 papers uploaded so cross-paper edges (methods / datasets / tasks) are visible.    |
| `analytics.png` | `/analytics` | Captured after ~20 queries so the 30-day trend chart has shape.                       |

Keep images under ~500 KB each (run them through `pngquant` or `oxipng` if needed) so the repo stays light.
